# Creator Breakout Brief — Bronte Harbour Classic 2026

**What this is:** A marketing strategy workbook adapted from the open-source
[Creator Breakout Kit](https://github.com/TheMattBerman/creator-breakout-kit)
by Matt Berman (Emerald Digital). Instead of running their Python pipeline
(built for paid creator campaigns with Virlo post-level data), we apply the
same discipline as a set of linked markdown docs — driven by the real brand
inputs we already have in this repo.

**Who it's for:** Liz, Patricia, Gus, Myles, Greg K. — the BHC5K marketing
sub-team. One page per stage. Each stage feeds the next.

**What it produces:** A prioritized, evidence-backed plan of which hooks,
angles, and content archetypes to test first — organic-first, with a paid
layer bolted on if budget opens up.

---

## Pipeline (read in order)

| # | File | Purpose |
|---|------|---------|
| 01 | `01-brand-snapshot.md` | Extract buyer objections, desires, and brand truths from our own materials |
| 02 | `02-breakout-patterns.md` | Identify post-level patterns from comparable races that *actually* broke out |
| 03 | `03-creator-archetypes.md` | Map patterns to the *roles* we need (not names) and who on our team fits each |
| 04 | `04-concept-slate.md` | 12 scored concept cards — hook, format, channel, archetype, objection |
| 05 | `05-test-plan.md` | Which 3 concepts launch first, success metrics, kill criteria, organic→paid path |
| 06 | `06-brief.html` | Single-page rendered brief for the marketing sub-team |

## How to use this

1. **Read 01 first.** It's the factual base for everything downstream. If you
   disagree with an objection or desire, fix it there — don't fix it in 04.
2. **Fill in 02 weekly.** Pattern research is the part that gets stale fastest.
   When Liz/Patricia/Gus are scrolling competing races on IG/TikTok, drop the
   standout posts into `02-breakout-patterns.md` with a line of why it worked.
3. **Treat 04 as a menu, not a mandate.** The concept slate has 12 ideas
   scored against four dimensions. Do *not* attempt all 12. Do the 3 from 05,
   learn, then come back.
4. **Re-score after each test.** When a concept wins or loses, update its
   "Confidence" label in 04 from Hypothesis → Directional → Strong (or kill).
5. **Feed winners into the content tool.** Once a concept has Directional or
   Strong evidence, add it as a Quick Preset to
   `../bronte-harbour-classic-content-creator-pro-v3.0.html` so the team can
   produce at volume without re-planning.

## What this is NOT

- Not a content calendar. See
  `../../7.Budget and KPIs/Task_Management_Sheets/04_Marketing_Liz_Patricia_Gus.csv`
  for the task tracker.
- Not a replacement for the Content Creator Pro tool. That tool is for
  *production*. This workbook is for *strategy* that sits upstream of it.
- Not a paid ads playbook. Paid appears in `05-test-plan.md` as an optional
  amplification layer once organic signal exists. Do not run paid against
  unvalidated creative.
