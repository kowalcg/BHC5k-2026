## 2. DECORATION & COLOR CONSIDERATIONS

### Key Pricing Factors:
- Each location (front, back, sleeve) is a separate charge
- Colors matter significantly:
  - On dark garments: Need white base layer (adds extra color charge)
  - Multiple colors: Each adds ~$0.20 per color on larger orders
  - Example: 3-color design on dark shirt = 4 colors total (with white base)

### Brent's Recommendations:
- **Back design:** Use single color to save costs
- **Front design:** Can do 2-3 colors
- **Sleeves:** Adds another $2-3 per location - expensive for limited space
- **Avoid:** Solid, fully-printed designs (makes shirts feel heavy/crunchy)
- **Use negative space:** Let shirt color show through the design for lighter feel

---

## 3. SHIRT OPTIONS & MATERIAL CHOICES

### Polyester vs Cotton:
- **Polyester is now cheaper than cotton** (textile industry shift)
- Performance polyester shirt: Same or lower price than basic cotton
- Ring spun cotton: Softer, upgraded option at similar price point

### Sizing Strategy Discussion:
- **Current plan:** Offering both men's and ladies' sizing
- **Challenge:** Managing 12+ size options for 800 people - inventory risk
- **Alternative:** Unisex (men's sizing) with ladies sizing down
- **Kids sizes:** Different sizing, more flexible, smaller quantities expected

### Decision Needed:
- You've already collected sizing data (men's/women's) online
- Continue with both, but be aware of inventory complexity

## 4. PRODUCTION METHOD: HEAT TRANSFER vs SCREEN PRINTING

### Brent's Recommendation: Heat Transfer Method

**Advantages:**
- Can run production in **2 waves** (flexible for late registrations)
- No incremental cost for second run
- No setup charges per run
- Faster turnaround for smaller batches

**Example Timeline:**
- **May 31st:** Produce 600 shirts (known registrations)
- **Week before race:** Produce 100 more shirts (late registrations)

### Screen Printing (Not Recommended):
- Setup charges for screens (~$300 per design variation)
- Each color = setup charge
- Expensive to run second batch
- Harder to manage with rolling registrations
- Better for 20,000+ shirts (like Toronto Maple Leafs quantities)
