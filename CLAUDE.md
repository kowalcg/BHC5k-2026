## Project Overview
This is the project directory for the **Bronte Harbour Classic 5K/10K Race**, organized by TapeGeeks. It covers event planning, sponsorships, vendors, race operations, budgeting, and marketing.

## Directory Structure
- `1. Sponsors-vendors/` — Sponsorship packages, vendor applications, outreach templates, CRM
- `2. Meetings/` — Meeting notes and follow-ups
- `3. Race Planning & Operations/` — Race day logistics and planning
- `4. Tools/` — Content creator tools and dashboards
- `5. Landing pages/` — Event landing pages (HTML)
- `6. bronte-dashboard/` — Project dashboard (HTML)
  - **Main Dashboard:** `BHC5K_PROJECT_DASHBOARD.html` — Primary project tracking dashboard with meetings, tasks, sponsors, budget, and all event management
- `7. Budget and KPIs/` — Budget tracking and KPI dashboards
- `9. Vendor Expo/` — Vendor expo planning

## Key Files
